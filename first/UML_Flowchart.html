sequenceDiagram
    autonumber
    actor User as 사용자
    participant Detail as ParkingDetailActivity
    participant VM as ParkingViewModel
    participant Rep as ParkingRepository
    participant DB as SQLite / Room (Local)
    participant Server as Remote Server / Firebase
    
    User->>Detail: 즐겨찾기 버튼(별 모양) 클릭
    Detail->>VM: toggleFavoriteStatus(parkingId)
    alt 현재 즐겨찾기 상태 = true
        VM->>Rep: removeFavorite(parkingId)
        Rep->>DB: DELETE FROM favorites WHERE parking_id = parkingId
        Rep->>Server: HTTP DELETE /favorites/{parkingId}
    else 현재 즐겨찾기 상태 = false
        VM->>Rep: addFavorite(parkingId)
        Rep->>DB: INSERT INTO favorites VALUES (parkingId, timestamp)
        Rep->>Server: HTTP POST /favorites (parkingId 데이터 전송)
    end
    Server-->>Rep: API Response (200 OK / 201 Created)
    Rep-->>VM: 업데이트 성공 완료 (Live Data/State Flow)
    VM-->>Detail: UI 상태 업데이트 (별 아이콘 활성/비활성 상태 반전)
    Detail-->>User: 토스트 알림 ("즐겨찾기에 추가되었습니다.")

    %% 백그라운드 지오펜싱 등록 %%
    Detail->>Geo: registerDestinationGeofence(parkingId, lat, lng)
    Geo->>GPS: GeofencingClient.addGeofences(Geofence object, PendingIntent)
    Note over Geo: 반경 100m, Dwell Delay 5s, 전환타입 ENTER 등록
    
    %% 주행 단계 %%
    User->>External: 내비 안내를 보며 운행 (우리 앱은 백그라운드 상태)
    
    %% 복귀 단계 %%
    GPS->>GPS: 실시간 GPS 비교 (목적지 반경 100m 이내 진입 감지)
    GPS->>System: PendingIntent 트리거 (GeofenceBroadcastReceiver 호출)
    System->>Geo: onReceive(context, Intent)
    
    %% 앱 강제 호출 %%
    Geo->>System: Notification 채널에 알림 발행 & Intent(ParkingDetailActivity) 실행
    Note over System: Android 10+ 백그라운드 실행 제약 준수를 위해
상단 헤드업 알림 팝업 후 탭하여 전환 처리
    System->>Detail: ParkingDetailActivity 재시작 (주차장 ID 파라미터 전달)
    Detail->>User: 주차장 상세화면 자동 표출 및 최신 도면/빈칸 실시간 렌더링

개발 계획서 삽입용 상세 명세

추가 기능 구현 설명 핵심 클래스 / API
1. 즐겨찾기 기능 각 주차장 정보에 즐겨찾기 상태를 적용하고 내부 Room DB와 원격 서버 DB를 비동기식으로 실시간 동기화합니다. Room DAO, Retrofit2 API, StateFlow
2. 실시간 도면 & 빈칸 표시 지도에서 주차장을 선택하면 해당 주차장의 CAD/SVG 기반 도면을 그리고 주차 구역별 빈칸(녹색)과 점유(적색) 상태를 센서 데이터와 연동하여 실시간 피딩합니다. Custom Drawing View, WebSocket / Firebase LiveDB
3. 외부 네비 앱 연동 "길찾기" 버튼 터치 시 안드로이드 Intent를 통해 카카오내비/티맵이 파라미터(위경도, 주차장 이름)를 물고 실행되도록 URI Scheme 호출을 실행합니다. kakaonavi://route, tmap://view_path, Intent.ACTION_VIEW
4. 지오펜싱 기반 자동 복귀 목적지 주차장 반경 100m 이내로 단말의 위치가 확인되면 백그라운드 BroadcastReceiver가 활성화되어 화면 알림과 함께 앱의 상세화면으로 자동 전환시킵니다. GeofencingClient, GeofenceBroadcastReceiver, PendingIntent
💡 작성 시 참고 사항
본 다이어그램과 흐름 명세는 카프스톤 디자인(또는 주요 개발 프로젝트) 중간/최종 보고서의 '시스템 흐름도(System Flowchart)' 및 '모듈별 상세 시퀀스 설계' 영역에 텍스트와 다이어그램 이미지로 다용도 삽입이 가능하도록 최적화되어 있습니다.
