# 07. 웹캠 영상 YOLO 1차 시험 (2026-10-16)

손으로 들고 녹화한 웹캠 영상 3개(`E:\ccapstione\Parkit\video\15·30·50.mp4`, 숫자는 카메라와 미니카 거리 cm)에서
기본 YOLOv8n(COCO 학습, 추가 학습 없음)이 도색 전 풀백 미니카를 차량(car·bus·truck)으로 잡는지 확인했다.

## 조건

- 영상: 1920×1080, 약 25fps(파일 표기는 60fps지만 실제 프레임 수 기준 약 25.6fps), 20~31초
- 3프레임마다 1장 분석, 신뢰도 0.25 이상을 검출로 봄
- "유효 프레임": 도면(흰 종이)이 화면에 보이고 너무 흐리지 않은 프레임만 집계. 천장·어두운 곳을 찍은 프레임과 심하게 흔들린 프레임은 제외
- 입력 크기(imgsz) 640(YOLO 기본)과 1280 두 가지로 비교

## 결과 (유효 프레임 중 차량으로 검출된 비율 / 평균 신뢰도)

| 거리 | 유효 프레임 | imgsz 640 | imgsz 1280 |
|---|---|---|---|
| 15cm | 182 | 37% / 0.48 | 0% |
| 30cm | 211 | 47% / 0.56 | **76% / 0.57** |
| 50cm | 141 | 0% | **63% / 0.56** |

- 오검출: 미니카를 bottle, airplane, backpack, cell phone 등으로 잡는 경우가 많음. 손은 person으로 잡힘.
- 예시 프레임: `docs/시험/yolo_예시_2026-10-16.jpg` (행: 15·30·50cm, 열: 가장 잘 잡힌 프레임 / 중간 프레임 / 놓친 프레임)

## 해석

1. **기본 모델로도 잡히긴 한다.** 30cm에서 최고 신뢰도 0.86으로 car 검출. 장난감 차여도 COCO 모델이 차로 인식할 여지는 있음.
2. **입력 크기가 중요하다.** 1080p 영상을 640으로 줄이면 50cm에서 미니카가 약 40픽셀로 작아져 전혀 못 잡음. 1280으로 넣으면 63%까지 올라감. 반대로 15cm처럼 차가 화면을 가득 채우면 1280에서 못 잡음.
3. **아직 시연 수준은 아니다.** 최고 76%이고 다른 물체로 착각하는 경우가 많음. 다만 이번 영상은 손으로 들어 흔들리고, 옆에서 낮게 비스듬히 찍고, 손이 화면에 들어온 조건이라 실제 설치 조건보다 불리함.

## 다음 단계 제안

1. 웹캠을 고정해 위에서 비스듬히 내려다보는 각도로 다시 촬영(손이 화면에 안 들어오게)
2. 칸이 있는 도면 영역만 잘라서(ROI) YOLO에 넣기: 해상도 손실 없이 차가 크게 보임
3. 도색 전후 비교 후, 그래도 70~80% 수준이면 모형 영상으로 추가 학습(파인튜닝)
