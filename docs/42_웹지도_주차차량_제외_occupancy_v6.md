# 42. 웹 지도 "보일 차량": 주차된 차 숨기기 → occupancy_v6 (2026-11-07)

주차장 이용자는 **통로에 있는 차 중에서 내 차가 무엇인지**만 알면 된다. 그래서 웹 지도에서 주차된 차를 숨길 수 있게 했다.
- 처음에는 `run.json` 설정으로만 고르게 만들었다(서버가 접점을 버림).
- 요청에 따라 **웹 화면에서 바로 고르도록** 바꿨다.
- 칸 판정(빈 칸 / 주차됨)은 바뀌지 않는다.

`occupancy_v6`에서 고쳤다. 커밋하지 않았다.

## 1. 쓰는 법

웹 지도(`python occupancy.py --web` → 브라우저 `http://127.0.0.1:8765`) 왼쪽에 **보일 차량** 칸이 생겼다.

```
보일 차량
 [ 전체 차량              ]
 [● 주차 확정 차량 숨기기  ]
 [ 주차칸 차량 모두 숨기기 ]
 주차가 확정된 칸의 차는 숨깁니다. 칸에 들어가는 중인 차는 확정될 때까지 보입니다. 지금 1대 숨김.
```

차 한 대가 ① 통로를 달리다 → ② 5번 칸에 들어가 멈추고 → ③ 3초 뒤 "주차됨"으로 판정되는 경우:

| 선택 | ① 통로 | ② 칸에 들어감 (판정 전) | ③ 주차 확정 뒤 |
|---|---|---|---|
| 전체 차량 | 보임 | 보임 | 보임 |
| 주차 확정 차량 숨기기 | 보임 | 보임 | **숨김** |
| 주차칸 차량 모두 숨기기 | 보임 | **숨김** | 숨김 |

- 고르면 바로 지도에 반영된다. 판정 프로그램을 다시 켤 필요가 없다.
- **보는 사람(브라우저)마다 따로** 정해진다. 이용자 휴대폰에서 바꿔도 다른 사람 화면에는 영향이 없다. 고른 값은 그 브라우저가 기억한다(다시 열어도 그대로).
- 주차된 차가 다시 통로로 나오면 세 가지 모두에서 다시 보인다.
- 칸 색(초록 빈 칸, 빨강 주차 중)은 그대로 보인다. 바뀌는 것은 차 아이콘뿐이다.
- 내 차로 고른 차가 숨겨지면 지도 위에 "내 차량이 N번 칸에 주차되어 지도에서 숨겼습니다…" 안내가 나오고, MY VEHICLE 칸에도 같은 내용이 나온다.
- 숨긴 차가 있으면 지도 아래 범례에 `주차 확정 차량 숨기기 · 1대`처럼 나온다.
- 휴대폰 화면(폭 850px 이하)에서는 보일 차량 칸을 화면 폭 전체로 넓혔다.

### 처음 값

그 브라우저에서 한 번도 고른 적이 없으면 `config\run.json`의 값을 쓴다. 기본은 전체 차량이다.

```json
"vehicle_tracking": { "parked_vehicles": "show" }
```

| 값 | 화면 이름 |
|---|---|
| `"show"` | 전체 차량 |
| `"hide_occupied"` | 주차 확정 차량 숨기기 |
| `"aisle_only"` | 주차칸 차량 모두 숨기기 |

모르는 값을 적으면 판정 프로그램이 시작할 때 오류를 낸다.

## 2. 어떻게 거르나

- **서버(판정 프로그램)는 늘 모든 차를 보낸다.** 차마다 마지막에 있던 칸 번호(`slot`)와 상자 종류(`kind`)가 붙어 있고, 칸 상태도 함께 보낸다.
- **웹 화면이 거른다**(`web/src/tracking.js`의 `shownByParking`).

| 차 종류 | 주차 확정 차량 숨기기 | 주차칸 차량 모두 숨기기 |
|---|---|---|
| `aisle` (통로 차) | 보임 | 보임 |
| `slot` (감시 칸에 선 차) | 그 칸이 OCCUPIED면 숨김 | 숨김 |
| `unmonitored` (감시하지 않는 칸에 선 차) | 그 칸이 OCCUPIED면 숨김(다른 카메라가 판정한 경우). 사각지대 칸이면 보임 | 숨김 |

- 웹이 칸 상태를 모르면(아직 못 받음) 숨기지 않는다.
- 판정 창(occupancy.py)의 평면도 접점은 그대로다.

## 4. 시험

- **웹 규칙** (`cd web && npm test`): 9 / 9 (새 시험 2개 포함)
  - 세 가지 선택에서 통로 차, 주차 확정 칸 차, 빈 칸 차, 사각지대 칸 차가 의도대로 보이거나 숨겨진다.
  - 처음 값은 "브라우저가 기억한 값 > run.json > 전체 차량" 순서다.
- **서버** (`python test_parked_vehicles.py`): 11 / 11
  - 설정 값과 오류를 확인했다.
  - 판정 프로그램(Engine)에 합성 남쪽 정면 카메라로 36번 칸 차와 통로 차를 넣었다. 주차 확정 뒤에도 서버는 두 차를 모두 보내고, 차에 칸 번호가 붙었다.
  - 같은 규칙으로 걸러 보면 판정 전(1.5초)과 확정 뒤(6.5초)가 위 표대로 나왔다.
- **브라우저 확인** (임시 합성 데모, 포트 8775):
  - 4번 칸 주차 확정 차, 7번 칸에 들어가는 중인 차, 통로 차를 띄웠다.
  - 전체 차량은 3대, 주차 확정 차량 숨기기는 2대(1대 숨김), 주차칸 차량 모두 숨기기는 1대(2대 숨김)가 보였다.
  - 4번 칸 차를 내 차로 고르고 숨기면 안내가 나왔다. 새로고침해도 고른 값이 남았다. 휴대폰 크기 화면도 확인했다.
- **기존 시험:**
  - test_aisle_contact_shift 16/16, test_pipeline 33/33
  - test_vehicle_tracker, test_tracking_integration, test_tracking_replay 통과

## 5. 남은 것

- 실제 웹캠으로 확인하지 않았다. 차를 칸에 넣고 3초 뒤(주차 확정) 지도에서 빠지는지, 통로로 빼면 다시 보이는지 본다.
- 칸 판정이 틀리면 거르기도 틀린다.
  - 통로 차를 칸 차로 오판하면(39 문서 A2, 대각선 카메라) 그 칸이 주차 확정되는 순간 그 통로 차가 숨겨진다.
  - 주차된 차가 "가림 / 확인 중"으로 남아 확정되지 않으면, 주차 확정 차량 숨기기에서는 계속 보인다. 그때는 주차칸 차량 모두 숨기기를 쓴다.
- 웹 화면을 고치면 `web`에서 `npm ci`, `npm run build`로 `web/dist`를 다시 만들어야 한다(Node 22.12 이상). `.gitignore`의 `dist/` 때문에 git에 올릴 때는 `git add -f`가 필요하다(38 문서 5절과 같음).
