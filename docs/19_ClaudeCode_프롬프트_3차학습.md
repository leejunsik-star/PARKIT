# Claude Code 작업 프롬프트: 3차 학습 데이터 정리 (2026-10-31)

5·6·7차 사진(다른 배경, 섞인 장면, 물체만)을 더해 M6~M8을 학습할 준비를 하는 작업이다. 아래 코드 블록을 Claude Code에 그대로 붙여 넣는다. 학습은 코랩에서 직접 돌린다.

## 1. 붙여 넣을 프롬프트

```text
[목표]
PARKIT의 3차 학습을 준비한다. 2차 학습(M1~M5)과 같은 방식으로 하되, 새로 찍은 5·6·7차를 더해 M6~M8을 학습하고 M5와 비교한다.
1) 5·6·7차를 배치 단위로 train/val/test로 나누고, 기존 split_2차 나누기와 합친 split_3차를 만든다.
2) 모델 3개(M6~M8)를 코랩에서 학습할 수 있게 묶는다.
3) 기존 시험 세트 T1~T5에 새 시험 세트 T6~T8을 더해 M5~M8을 채점하는 스크립트를 만든다.

[대상]
- 프로젝트 폴더: E:\ccapstione\Parkit (CLAUDE.md 참고)
- 기존 2차 학습 자료: dataset\split_2차(나누기, 목록, yaml, 확인결과.txt), docs\도구\make_split_2차.py, docs\도구\colab_train_2차.ipynb, docs\도구\eval_2차.py, docs\17_2차학습_실행방법.md, docs\18_2차학습_결과분석.md
- 기존 모델: docs\도구\models\M1.pt ~ M5.pt (M5 = 1·2·4차 + 3차 21장 + COCO 60장, 현재 최선)
- 새 데이터 (hun이 라벨 검수 완료):
  - data_5차(other_bg) 25장 bg_{1-6}_{번호}.jpg / labels_5차(other_bg): 다른 배경(책, 상자, 종이 주차장) 위 미니카
  - data_6차(mixed) 51장 mix_{1-9}_{번호}.jpg / labels_6차(mixed): 매트 위 미니카 + 차 아닌 물체. mix_7~9는 어두운 조명
  - data_7차(obj_only) 35장 obj_{1-6}_{번호}.jpg / labels_7차(obj_only): 매트 위 물체만, 빈 txt
  - 각 labels 폴더의 labels.txt(car)는 클래스 목록이라 사진 라벨이 아니다

[현재 상태]
- 2차 결과(18 문서): M5가 차 탐지와 매트 밖 오탐 모두 가장 좋았다. 하지만 매트 위에 올린 다른 물체는 여전히 차로 잡는다. M5로 7차(차 없음)를 돌리면 35장에서 상자 72개가 나왔다.
- 학습 설정: yolo26n.pt에서 처음부터, imgsz=640, epochs=100, batch=16, hsv_h=0.05 (코랩 T4).

[나누기 기준 (배치째로 나눈다)]
- 1~4차, 3차, COCO: split_2차와 똑같이 (기존 T1~T5와 val 그대로)
- 6차: test mix_4·mix_9(T6), val mix_5, train 나머지(mix_1~3, mix_6~8)
- 7차: test obj_6(T7), val obj_5, train obj_1~4
- 5차: test bg_6(T8), val bg_5, train bg_1~4

[모델 3개의 train 구성 (val·test는 모두 같다)]
- M6: M5 train + 6차 train
- M7: M6 + 7차 train
- M8: M7 + 5차 train (= 전부)
M5는 다시 학습하지 않고 기존 M5.pt를 쓴다. 단, val에 새 배치가 추가되므로 M5도 같은 채점 스크립트로 다시 채점한다.

[만들 것]
1. docs\도구\make_split_3차.py와 dataset\split_3차\ : make_split_2차.py를 바탕으로 새 이름으로 만든다(기존 파일은 고치지 않음). 모델별 목록(train_M6~M8.txt)과 yaml, 시험 세트별 yaml(T1~T8), 확인결과.txt
2. 코랩에 올릴 압축 파일 하나(split_3차 전체)
3. docs\도구\colab_train_3차.ipynb : colab_train_2차.ipynb와 같은 방식으로 M6~M8 학습. 끝난 모델은 건너뛰고 이어서 학습할 수 있게 한다.
4. docs\도구\eval_3차.py : eval_2차.py를 바탕으로 새로 만든다.
   - 모델: best.pt, M5, M6, M7, M8 (M1~M4는 빼도 됨)
   - T1~T3, T6, T8 (차 있음): P, R, mAP50, 그리고 신뢰도 0.25에서 놓친 차 수와 잘못 잡은 상자 수(상자가 정답과 50% 이상 겹치면 맞음)
   - T4, T5, T7 (차 없음): 신뢰도 0.25에서 잘못 잡은 상자 수, 오탐 있는 사진 비율
   - 결과는 csv와 마크다운 표 하나로 docs\도구\eval_3차_결과\에 저장
5. docs\20_3차학습_실행방법.md : 위 파일들 쓰는 순서와 결과 표 빈칸

[제약 조건]
- data_*·labels_* 원본 폴더는 수정하거나 옮기지 않는다. 복사만 한다.
- split_2차, handoff_2차, 2차용 스크립트와 노트북은 고치지 않는다. 3차용은 새 이름으로 만든다.
- E:\ccapstione\first 는 읽기만 하고 절대 수정하지 않는다.
- 코드는 Windows와 맥에서 모두 돌게 쓴다(docs\13 3절 규칙).
- 설명, 주석, 문서는 한국어로 쓴다. 결과 문서는 docs 폴더에 마크다운으로 둔다.

[완료 조건]
- split_3차의 출처별·나누기별 사진 수, 라벨 수, 상자 수 표가 확인결과.txt에 있고, 같은 배치가 두 나누기에 걸치지 않으며, 1~4차·3차·COCO의 나누기가 split_2차와 같음을 스크립트로 확인한다.
- 모든 사진에 같은 이름의 라벨 txt가 있다(차 없는 사진은 빈 파일). 파일명이 출처끼리 겹치지 않는다.
- eval_3차.py를 기존 best.pt와 M5.pt로 실제 실행해서 표가 나온다.
- 코랩 노트북은 코랩에서 열면 바로 실행할 수 있는 상태다(실제 학습은 내가 돌린다).

[작업 방식]
- 큰 변경 전에 계획(만들 파일, 나누기 결과 표)을 먼저 보여주고 확인을 받는다.
- 끝나면 만든 파일과 사진 수 표를 요약해서 보여준다.
```
